# `Executables/`

Сценарии и утилиты, вызываемые из playbook. Всё, что не выражается декларативным действием, живёт здесь — но не в виде однострочников в YAML.

**Статус:** пусто до v0.1. Здесь зафиксирован контракт, не реализация.

| Файл (план) | Роль | Вызывается |
|---|---|---|
| `preflight` | снять prior-state по плану изменений, проверить окружение, сохранить снимок | фаза `00` |
| `verify` | проверить постусловия и инварианты, ничего не менять | фаза `90` |
| `report` | собрать отчёт: применено / не применено / необратимо | фаза `90` |
| `revert` | вернуть prior-state в обратном порядке | вручную или отдельным прогоном |

Требования:

1. Работают без интерактивного ввода — playbook исполняется автоматически.
2. Не требуют сети.
3. Пишут результат в машиночитаемом виде и отдельно — человекочитаемый отчёт.
4. Идемпотентны: повторный запуск не ломает состояние.
5. Не содержат зашитых значений, которые дублируют YAML, — иначе конфигурация разъедется.

Контракт верификации: [VERIFICATION](../../docs/VERIFICATION.md). Откат: [REVERT](../../docs/REVERT.md).
