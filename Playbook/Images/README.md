# `Images/`

Иконки для элементов `<Software>` в `playbook.conf` и для OOBE.

**Статус:** пусто.

Требования:

1. Формат PNG, прозрачный фон, квадрат.
2. Имя файла — строчными буквами без пробелов; ссылка из `playbook.conf` указывает на файл внутри этой папки.
3. Иконка `playbook.png` (256 px) лежит **не здесь**, а в корне `Playbook/` — это отдельное требование AME.
