# `Configuration/Tasks/`

Фазовые файлы задач. Имя = `NN-название.yml`, где `NN` — порядковый номер фазы.

**Статус:** пусто до v0.1.

Требования к каждому файлу:

1. `title` в шапке файла — осмысленный, не «Registry».
2. Только действия одной категории.
3. Действия, которые нельзя откатить, помечены гейтом (`option`) и попадают в отчёт как необратимые.
4. Действие службы — только из allowlist ([SAFETY](../../../docs/SAFETY.md) §3).
5. Динамические действия (`!cmd`, `!powerShell`, `!run`, `!appx`, `!systemPackage`, `!taskKill`) не должны иметь `iso: true`.
6. Никаких одноразовых команд: всё, что требует сценария, живёт в `../Executables/`.

Ссылки по теме: [ACTIONS](../../../docs/ACTIONS.md), [PARAMETERS](../../../docs/PARAMETERS.md).
