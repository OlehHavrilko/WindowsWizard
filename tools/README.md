# `tools/`

Офлайн-инструменты сборки. Код появится на этапе v0.1; здесь зафиксирован контракт ([BUILD](../docs/BUILD.md)).

| Инструмент (план) | Роль | Код возврата |
|---|---|---|
| `validate.py` | проверить структуру, метаданные, лимиты FeaturePages, совместимость `iso:`, ссылочную целостность, порядок фаз | `0` — можно упаковывать; иначе — ошибки с путями |
| `package.py` | собрать `.apbx` (7z, пароль `malte`), посчитать SHA-256, положить в `releases/` | `0` / ненулевой |

Правила:

1. Инструменты ничего не меняют в `Playbook/` — только читают.
2. Валидатор запускается всегда, в том числе при правке одной строки.
3. Упаковщик отказывается собирать, если валидатор вернул ошибки.
4. Версия AME Wizard, на которой проверялось, фиксируется в отчёте о сборке.
