# `tests/`

Тестовая матрица — [../docs/TEST-MATRIX.md](../docs/TEST-MATRIX.md). Здесь хранятся артефакты прогонов.

**Статус:** пусто, среда ещё не создавалась.

Что попадает сюда на каждый прогон:

```
tests/artifacts/<YYYY-MM-DD>-<версия>-<среда>/
├── result.md            запись по форме из TEST-MATRIX §4
├── preflight.json       снимок prior-state
├── verify.json          результаты проверок
├── report.html          человекочитаемый отчёт
└── notes.md             замечания и объяснение расхождений
```

Правила:

1. Артефакты в репозиторий не коммитятся (см. `.gitignore`).
2. Провал любого инварианта — блокирующий дефект, а не «известная особенность».
3. Каждый найденный дефект превращается в строку регрессии в матрице.
