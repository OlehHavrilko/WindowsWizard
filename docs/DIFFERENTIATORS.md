# Отличия: чем WindowsWizard конкурирует

Список функций, которых нет у AtlasOS, ReviOS, Privacy+ и AME 11 по состоянию на 2026-11-11. Обоснование — [COMPETITORS](COMPETITORS.md) (слабые места W-01…W-09), позиционирование — [DECISIONS](DECISIONS.md) D-014.

Все пункты — замысел: ни один не реализован и не проверен. Сложность оценочная.

## 1. Принцип

Не «убрать больше», а **доказать каждое изменение и уметь его вернуть**. Решительность проекта — в смелых опциях, которые становятся допустимыми именно потому, что есть проверка и откат (линия Lab, §4).

## 2. Ядро

Уже заложено в документации; задача — довести до видимого пользователю результата.

| ID | Функция | Суть | Закрывает | Сложность | Этап |
|---|---|---|---|---|---|
| F-01 | Proof Report | после прогона по каждому параметру: `applied` / `mismatch` / `silently ignored`; HTML-отчёт, читаемый без знания playbook ([VERIFICATION](VERIFICATION.md)) | W-01 | средняя | v0.1 текст, v0.2 HTML |
| F-02 | Откат по исходному состоянию | возврат к снятому prior-state в обратном порядке, с перечнем необратимого до применения ([REVERT](REVERT.md)) | W-02 | высокая | v0.1 минимальный, v0.2 полный |
| F-03 | Карточки как единый источник | из карточек параметров ([PARAMETERS](PARAMETERS.md)) генерируются YAML playbook, проверки верификатора, шаги отката и публичный каталог «что это ломает» | W-01, W-07 | высокая | v0.2 формат, v0.5 генерация |

### 3.1 Ограничения

| ID | Ограничение |
|---|---|
| F-04 | на ISO-пути план строится по образу, а не по живой системе; расхождение описано в [ARCHITECTURE](ARCHITECTURE.md) §2.2 |
| F-05 | постоянная запланированная задача — новое изменение системы: нужна карточка параметра, откат и отключение одной командой; автоматического переприменения без подтверждения нет |
| F-06 | замер на ВМ не переносится на физическую машину; frametime требует воспроизводимой сцены, иначе шум больше эффекта |
| F-07 | проверка предпосылок античита не гарантирует его запуск; фактический запуск — ручной пункт приёмки |
| F-08 | платформа не имеет условной логики ([ACTIONS](ACTIONS.md) §5): выбор набора возможен только через опции или собственный сценарий, это надо проверить на закреплённой версии AME |

## 4. Линия Lab

Отдельный набор опций, выключенных по умолчанию, — то, чего конкуренты избегают из-за необратимости. Решение — [DECISIONS](DECISIONS.md) D-015 (`proposed`).

Опция попадает в Lab только при трёх условиях одновременно:

1. **Локальный бэкап** удаляемого или изменяемого до применения (экспорт пакета, ключей, задач).
2. **Проверенный откат** — отдельный прогон по [TEST-MATRIX](TEST-MATRIX.md), возвращающий состояние из бэкапа без сети.
3. **Замер или иное доказательство эффекта** — в отчёте, а не в описании.

| ID | Кандидат | Чем доказывается эффект | Главный риск |
|---|---|---|---|
| F-10a | Полное удаление Copilot / Recall / AI-компонентов оболочки | отсутствие пакетов и процессов после обновления (F-05) | возврат компонентов обновлением; зависимость других приложений |
| F-10b | Удаление Edge с сохранением WebView2 | работоспособность приложений на WebView2 | поломка встроенных веб-компонентов и входа в учётную запись |
| F-10c | Управляемое кольцо обновлений: исправления безопасности сразу, обновления функций — отложенно, снимок состояния перед установкой | система получает исправления, Drift Guard не находит потерь | остаток «управляется организацией» ([RISKS](RISKS.md) R-12) |
| F-10d | Сетевое доказательство приватности: захват исходящих соединений до и после | сокращение числа обращений к телеметрическим узлам | методика захвата на свежей системе нестабильна |

По решению D-017 кандидаты F-10a и F-10b перенесены в пресет «Стандарт» Toolbox ([TOOLBOX](TOOLBOX.md) §3) с сохранением трёх условий.

Lab не обходит запреты [SAFETY](SAFETY.md) §4: Defender, VBS, Windows Update, BCD, WinSxS и Driver Store остаются вне набора (F-11). F-10c не отключает обновления и потому не противоречит [DECISIONS](DECISIONS.md) D-006; она закрывает открытый вопрос Q-02.

## 5. Адаптация к обновлениям Windows

Причина, по которой люди обходят такие playbook стороной: отключённый Defender и обновления, заблокированные политиками, после которых обновить Windows — отдельная задача. Наш принцип ([DECISIONS](DECISIONS.md) D-019): пользователь всегда может поставить свежую версию Windows, и ничего не ломается.

| ID | Механизм | Суть | Этап |
|---|---|---|---|
| F-12a | Обновления без блокировок | ни одной политики, запрещающей Windows Update; после нашего прогона «Проверить обновления» работает штатно — это инвариант верификатора | v0.1 |
| F-12b | Проверка новых сборок заранее | CI прогоняет набор на ВМ с Insider- и свежими накопительными сборками до их массового выхода; результат — таблица «сборка → что сломалось» | v0.5 |
| F-12c | Манифест совместимости | для каждой сборки Windows — список параметров: работает / изменён / отключён; Toolbox подгружает его с проверкой подписи (T-07) | T-v0.3 |
| F-12d | Drift Guard после обновления | F-05: что система вернула, что переприменить; по манифесту несовместимое не переприменяется | v0.2 |
| F-12e | Обновление функций без переустановки | переход 26H2 → следующая версия: до установки — снимок состояния, после — сверка и доведение; переустановка Windows не требуется | после v1.0 |

Закрывает W-03 и W-04 ([COMPETITORS](COMPETITORS.md)). Ограничение: F-12b требует постоянной инфраструктуры ВМ; без неё манифест отстаёт от выхода сборок.

## 6. Чего сознательно не делаем

| Не делаем | Почему |
|---|---|
| Отключение Defender и блокировка обновлений политиками | [DECISIONS](DECISIONS.md) D-002, D-006, D-019 |
| Соревнование по числу удалённых компонентов | поле занято, эффект не доказан ([COMPETITORS](COMPETITORS.md) §4) |
| Второй набор скриптов в Toolbox, не связанный с карточками | [DECISIONS](DECISIONS.md) D-016 |
| Закрытые программы в каталоге | [TOOLS-CATALOG](TOOLS-CATALOG.md) |
| Обещания прироста FPS в описании | только числа из F-06 на конкретной машине |
| Опции, которые молча не работают | [DECISIONS](DECISIONS.md) D-002 |

## 7. Порядок ценности

Если ресурсов хватит не на всё: F-04 → F-01 → F-02 → F-05 → F-07 → F-06 → остальное. Первые четыре дают то, чего нет ни у кого, и не требуют спорных решений.
