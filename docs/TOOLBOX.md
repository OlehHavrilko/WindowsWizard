# Toolbox: приложение после установки

Замысел владельца от 2026-11-11, решения — [DECISIONS](DECISIONS.md) D-016…D-018. Ничего не реализовано; всё, что зависит от внешних сервисов, помечено «требует проверки».

## 1. Разделение ролей

| Слой | Когда | Что делает |
|---|---|---|
| Playbook (`.apbx`) | при установке | обязательный минимум: то, без чего система не считается настроенной |
| Движок | основа обоих слоёв | каталог карточек и команды `plan` / `apply` / `verify` / `revert` |
| Toolbox | после установки, в любой момент | всё по выбору: пресеты твиков, драйверы, программы, обновления, отчёты, откат |

Правило: любой твик Toolbox описан той же карточкой параметра ([PARAMETERS](PARAMETERS.md)), имеет проверку и откат. Toolbox — интерфейс к тем же данным, а не второй набор скриптов.

## 2. Вкладки

| Вкладка | Содержимое |
|---|---|
| Обзор | состояние системы, последний Proof Report, дрейф после обновлений (F-01, F-05) |
| Твики | пресеты (§3) и отдельные переключатели; у каждого — «что ломает» и кнопка «вернуть» |
| Драйверы | определение железа и установка драйверов без браузера (§4) |
| Программы | каталог open source ([TOOLS-CATALOG](TOOLS-CATALOG.md)), установка пачкой |
| Обновления | режим обновлений Windows: всё / только безопасность / отложить функции (F-10c) |
| Замеры | замер до и после (F-06) |
| Откат и отчёты | история прогонов, откат одного твика или всего прогона (F-02) |

## 3. Пресеты твиков

| Пресет | Состав | По умолчанию |
|---|---|---|
| Стандарт | телеметрия, реклама и рекомендации, Copilot / Recall / AI-функции оболочки, удаление Edge с сохранением WebView2, потребительские Appx, базовые настройки оболочки | предлагается при первом запуске |
| Игры | планировщик и питание, Game Mode, фоновые службы из allowlist, настройки ввода | по выбору; каждый параметр — с замером |
| Разработка | проверка и включение WSL2, виртуализации, длинных путей, Dev Drive | по выбору |
| Lab | необратимое и спорное при трёх условиях ([DIFFERENTIATORS](DIFFERENTIATORS.md) §4) | выключено |

«Оптимизация ядра» (таймеры, приоритеты, параметры планировщика) идёт в «Игры» только с замером на этой машине ([DECISIONS](DECISIONS.md) D-011); без эффекта параметр в пресет не попадает. Запреты [SAFETY](SAFETY.md) §4 действуют для всех пресетов.

## 4. Драйверы

Цель: человек не открывает браузер и сайт производителя.

| Что | Способ | Надёжность |
|---|---|---|
| Определение железа | WMI / PnP: GPU, чипсет, сеть, звук, модель платы | штатно |
| NVIDIA GPU | запрос последней версии по модели и ОС, загрузка с серверов NVIDIA, тихая установка; по умолчанию чистый пакет — только драйвер; отдельная вкладка инструментов NVIDIA ([DECISIONS](DECISIONS.md) D-024) | официального API нет, используется неофициальная точка — требует проверки |
| AMD GPU и чипсет | официальный AMD Auto-Detect либо прямая загрузка пакета Adrenalin, тихая установка | официального API нет; прямая загрузка зависит от заголовков запроса — требует проверки |
| Intel GPU, сеть, Wi-Fi | Intel Driver & Support Assistant или пакеты через winget | требует проверки |
| Остальное (сеть, звук, устройства платы) | драйверы из каталога Windows Update по идентификаторам устройств | штатно, версии могут отставать |
| Материнская плата (утилиты, BIOS) | только ссылка на страницу модели; BIOS не обновляется автоматически | единого источника не существует |

Правила: перед установкой драйвера — точка восстановления; версия до и после — в отчёте; загруженный файл проверяется по цифровой подписи производителя; при неудачном определении — честное «не найдено», без установки наугад.

## 5. Технология

| Вопрос | Решение |
|---|---|
| Стек | C# и WinUI 3; вся логика — в общем движке .NET с командами `plan` / `apply` / `verify` / `revert` ([DECISIONS](DECISIONS.md) D-023) |
| Установка программ | winget; идентификаторы хранятся в каталоге и проверяются CI |
| Данные | единый каталог карточек: из него строятся и playbook, и интерфейс (F-03) |
| Права | запуск с повышением; каждое действие пишется в журнал прогона ([EXECUTION-CONTRACT](EXECUTION-CONTRACT.md)) |
| Языки | русский, украинский, английский |

## 6. Дополнения к замыслу

| № | Идея | Зачем |
|---|---|---|
| T-01 | Профиль в одном файле: выбранные твики, программы, настройки; экспорт и импорт | после переустановки Windows система восстанавливается одной кнопкой; профилем можно поделиться |
| T-02 | Точка восстановления перед каждым прогоном автоматически | страховка без участия пользователя |
| T-03 | Проверка готовности к античитам: Secure Boot, TPM, HVCI — с объяснением, что включить | F-07 в виде кнопки |
| T-04 | Чистая переустановка драйвера GPU: удаление старого перед установкой нового | типовая причина проблем после смены видеокарты |
| T-05 | Здоровье системы: SFC / DISM, состояние дисков, температуры, автозагрузка | замена нескольких отдельных утилит |
| T-06 | Загрузка оригинального ISO и сборка установочного носителя с playbook | полный цикл в одном инструменте |
| T-07 | Обновление самого Toolbox и каталога с проверкой подписи | каталог устаревает быстрее кода |
