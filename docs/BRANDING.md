# Фирменный стиль WizardOS

Замысел владельца от 2026-11-11, решение — [DECISIONS](DECISIONS.md) D-028. Это концепция и дизайн-документ; реализация — в конце проекта, после движка, playbook и каркаса Toolbox ([ROADMAP](ROADMAP.md)). Исполнитель реализации — агент `designer` (`.claude/agents/designer.md`).

## 1. Принципы

1. **Бренд виден сразу после установки**: обои, тема, акцент, экран блокировки и Toolbox складываются в одну узнаваемую картинку, как у ReviOS и AtlasOS.
2. **Бренд — такие же карточки, как твики.** Каждое изменение оформления — карточка `brand.*` в каталоге движка ([PARAMETERS](PARAMETERS.md)) со снимком исходного состояния, проверкой и откатом. Отдельных скриптов оформления нет (D-023).
3. **Только своё.** Все изображения, знак и иконки рисуются в репозитории из исходников (SVG и скрипт рендера). Чужие обои, логотипы, шрифты и иконпаки не используются.
4. **Системные файлы не трогаются.** Не заменяются `img0.jpg`, `imageres.dll`, загрузочный логотип, системные звуки и курсоры: это файлы TrustedInstaller, их возвращают SFC и обновления, а замена ломает D-019.
5. **Пользователь не заперт.** Оформление ставится как обычная пользовательская настройка, без политик, блокирующих смену обоев или экрана блокировки.

## 2. Как это делают другие

### 2.1. Что видно у ReviOS и AtlasOS

| Проект | Что видно после установки | Уверенность |
|---|---|---|
| ReviOS | красные фирменные обои, тёмная тема, сведения о системе в «Параметры → О системе», собственная утилита Revision Tool | по публичным материалам и скриншотам; исходники не прочитаны |
| AtlasOS | фирменные обои в нескольких пропорциях (4:3, 16:9, 16:10, 21:9), тёмная тема, папка настроек на рабочем столе, набор бренда на docs.atlasos.net/branding | обои и пропорции — подтверждены страницей бренда; механизм применения не прочитан |

Исходники обоих playbook из этой среды не читаются (GitHub закрыт для автоматического чтения). Перед реализацией `designer` сверяет §2.2 с актуальными `.yml` обоих проектов на машине владельца и обновляет таблицу. Опираться можно только на §2.2: это штатные механизмы Windows, не зависящие от чужого кода.

### 2.2. Механизмы Windows, через которые применяется оформление

| Что | Механизм | Область | Откат | Решение для WizardOS |
|---|---|---|---|---|
| Обои рабочего стола | файл в `%WINDIR%\Web\Wallpaper\WizardOS\`, значение `HKCU\Control Panel\Desktop\Wallpaper` + `SystemParametersInfo(SPI_SETDESKWALLPAPER)` | пользователь | вернуть прежний путь и стиль из снимка | **да** |
| Тема целиком | файл `%WINDIR%\Resources\Themes\WizardOS.theme` (обои, акцент, режим); тема появляется в «Персонализация → Темы» | машина (файл), пользователь (выбор) | удалить файл, вернуть прежнюю тему | **да**, как носитель набора |
| Новые пользователи | значения в профиле Default (`C:\Users\Default\NTUSER.DAT`), применяются на этапе OOBE | профиль по умолчанию | снимок значений куста Default | **да**, только при установке |
| Тёмный режим | `HKCU\Software\Microsoft\Windows\CurrentVersion\Themes\Personalize`: `AppsUseLightTheme`, `SystemUsesLightTheme` = 0 | пользователь | значения из снимка | **да** |
| Акцентный цвет | `HKCU\Software\Microsoft\Windows\DWM`: `AccentColor`, `ColorizationColor`, `ColorPrevalence`; `HKCU\...\Explorer\Accent`: `AccentPalette`, `AccentColorMenu`, `StartColorMenu` | пользователь | значения из снимка | **да** |
| Экран блокировки | API `Windows.System.UserProfile.LockScreen.SetImageFileAsync` в контексте пользователя | пользователь | вернуть Windows Spotlight или прежнее изображение | **да**, только этим способом |
| Экран блокировки через политику | `HKLM\...\PersonalizationCSP` (`LockScreenImagePath` / `Status`) | машина | удалить ключ | **нет**: запрещает пользователю менять экран |
| Блокировка обоев политикой | `HKCU\...\Policies\System\Wallpaper` | пользователь | — | **нет**: запирает выбор пользователя |
| Сведения о поставщике | `HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\OEMInformation`: `Manufacturer`, `SupportURL`, `Logo` (BMP 120×120) | машина | значения из снимка | **да**, только если ключ пуст (не затирать данные производителя ПК) |
| Аватар учётной записи | `%ProgramData%\Microsoft\User Account Pictures\` | машина | — | **нет**: файлы системы, ценность мала |
| Курсоры, звуки, системные иконки | `HKCU\Control Panel\Cursors`, `AppEvents`, ресурсы DLL | — | — | **нет** (принцип 4) |
| Загрузочный логотип | замена в загрузчике / прошивке | — | — | **нет**: Secure Boot, необратимо |
| Ярлык Toolbox | закрепление в «Пуске», ярлык на рабочем столе | пользователь | удалить ярлык | **да**, ставится вместе с Toolbox |
| Страницы AME Wizard | `playbook.png` 256 px, `Title`, `ShortDescription`, `Description` в `playbook.conf` ([PLAYBOOK-CONF](PLAYBOOK-CONF.md)) | — | — | **да** |

## 3. Идея

**«Ясная магия».** Волшебник в WizardOS — не фокусник, а мастер, у которого каждое заклинание записано, проверено и снимается. Отсюда визуальный язык: тёмное ночное небо, тонкие линии чертежа и созвездий, точные геометрические знаки. Ни дыма, ни огня, ни черепов, ни «геймерского» неона.

Противопоставление конкурентам: ReviOS — красный и агрессивный, AtlasOS — синий и нейтральный. WizardOS — **глубокий фиолетовый с мятной «печатью проверки»**. Мятный цвет закреплён за смыслом «доказано» (F-01, D-014) и в интерфейсе означает только его.

Метафоры для интерфейса и текстов:

| Понятие проекта | Образ |
|---|---|
| Карточка твика | руна: у каждой есть смысл, проверка и обратное заклинание |
| Proof Report | печать: подтверждение, что изменение на месте |
| Откат | снятие заклинания |
| Дрейф после обновления | потускневшая печать |

Метафоры живут в иллюстрациях и пустых состояниях. В кнопках и статусах — обычные слова: «Применить», «Вернуть», «Проверено».

## 4. Палитра

| Токен | Цвет | Роль |
|---|---|---|
| `Ink` | `#0E0B1A` | фон тёмной темы, фон обоев |
| `Night` | `#1A1530` | поверхности, карточки |
| `Arcane` | `#7C5CFF` | акцент: Windows-акцент, выделение, ссылки, знак |
| `ArcaneDeep` | `#5B3DF0` | заливка основной кнопки с белым текстом |
| `Glyph` | `#B9A6FF` | вторичный акцент, линии на обоях, акцент на тёмном фоне |
| `Text` | `#ECE8FF` | основной текст на тёмном |
| `Muted` | `#9C95B8` | вторичный текст на тёмном |
| `Parchment` | `#F6F3FF` | фон светлой темы |
| `Proof` | `#3DDC97` | только «проверено», применено и подтверждено |
| `Ember` | `#FFB547` | предупреждение, дрейф, нужна перезагрузка |
| `Hex` | `#FF5A6E` | ошибка, не применилось, откат не прошёл |

Контраст (WCAG 2.x), посчитан: `Text`/`Ink` 16.2; `Muted`/`Ink` 6.9; `Glyph`/`Ink` 9.2; `Proof`/`Ink` 11.0; `Ember`/`Ink` 11.1; `Hex`/`Ink` 6.4; белый/`ArcaneDeep` 6.2; `ArcaneDeep`/`Parchment` 5.7. `Arcane`/`Ink` 4.5 и белый/`Arcane` 4.35 — только для крупных элементов и иконок, не для основного текста; поэтому кнопки заливаются `ArcaneDeep`.

Windows-акцент — `#7C5CFF`. Остальные оттенки акцента (`AccentPalette`) Windows строит сама; `designer` сохраняет готовую палитру из «Параметров» эталонной машины, а не подбирает вручную.

Статусные цвета не используются как декор. Цвет никогда не единственный носитель смысла: у статуса всегда есть иконка и слово.

## 5. Типографика

| Назначение | Шрифт | Почему |
|---|---|---|
| Интерфейс Toolbox | Segoe UI Variable (системный) | штатный шрифт Windows 11, лицензия покрыта ОС, ничего не поставляем |
| Журнал, ключи реестра, команды | Cascadia Mono; запасной — Consolas | открытая лицензия OFL; наличие в чистой 26H2 требует проверки |
| Знак и надпись WizardOS | собственная надпись в кривых (SVG) | не зависит от шрифта; уникальна |

Шкала — типовые стили WinUI 3 (Caption, Body, BodyStrong, Subtitle, Title, Display) без своих размеров. Вес надписи знака — близкий к Semibold, буквы с прямыми срезами.

## 6. Знак

**«Печать».** Монограмма `W`, у которой правый штрих продолжается в галочку: «W» и «проверено» — один росчерк. Знак вписан в восьмиугольник из тонкой линии (рамка печати).

| Вариант | Где |
|---|---|
| Полный: печать + надпись WizardOS | README, страница AME Wizard, «О программе» в Toolbox |
| Только печать | иконка Toolbox, `playbook.png`, логотип в OEMInformation, favicon |
| Монохромный | экран блокировки, водяной знак обоев, отчёты для печати |

Требования: читается в 16 px; работает в один цвет; не похож на знаки Windows, AtlasOS, ReviOS и известных игровых брендов (проверка — до утверждения). Исходник один — `branding/src/mark.svg`; все растровые размеры получаются скриптом.

## 7. Обои и экран блокировки

**Сюжет:** ночное небо `Ink`, по нему — тонкая сетка чертежа и несколько орбит-созвездий линиями `Glyph` с низкой непрозрачностью; в узлах — точки `Arcane`; одна точка `Proof`. Печать — едва заметным водяным знаком или отсутствует. Центр и левый верх свободны под иконки рабочего стола.

| Набор | Содержание |
|---|---|
| `wizardos-dark` | основной, по умолчанию |
| `wizardos-light` | `Parchment` и тонкие линии `ArcaneDeep` — для светлой темы |
| `wizardos-lock` | больше пустого места под часы и поле входа, печать внизу |
| `wizardos-plain` | только градиент `Ink` → `Night`, без рисунка — для тех, кто хочет тише |

Разрешения: 3840×2160 (16:9), 2560×1600 (16:10), 5120×2160 (21:9), 2732×2048 (4:3). Формат — JPEG качества 92: размер `.apbx` ограничен ([PLAYBOOK-CONF](PLAYBOOK-CONF.md) §7). Обои — **генерация скриптом** из SVG/параметров (`tools/branding/render`), результат воспроизводим и не зависит от сторонних изображений или генеративных моделей с неясной лицензией.

## 8. Что применяется при установке

FeaturePage «Оформление» в playbook, три варианта:

| Вариант | Состав | По умолчанию |
|---|---|---|
| Полное | все карточки ниже | да |
| Только тема | тёмный режим и акцент, без обоев и экрана блокировки | — |
| Не менять | ничего из `brand.*`; Toolbox и его ярлык ставятся всё равно | — |

Карточки (все T1, класс устойчивости A, статус `proposed`):

| ID | Что делает | Область |
|---|---|---|
| `brand.assets.files` | копирует обои и `WizardOS.theme` в `%WINDIR%\Web\Wallpaper\WizardOS\` и `%WINDIR%\Resources\Themes\` | машина |
| `brand.theme.dark` | тёмный режим системы и приложений | пользователь + Default |
| `brand.accent.color` | акцент `#7C5CFF`, акцент в заголовках выключен | пользователь + Default |
| `brand.wallpaper.desktop` | обои `wizardos-dark` под пропорцию экрана | пользователь + Default |
| `brand.lockscreen.image` | `wizardos-lock` через API LockScreen | пользователь |
| `brand.oem.info` | `Manufacturer = WizardOS`, `SupportURL` = страница проекта, `Logo` — печать; только при пустом ключе | машина |
| `brand.toolbox.shortcut` | ярлык Toolbox в «Пуске» | пользователь |

`brand.assets.files` — зависимость остальных; без неё ни одна карточка не применяется. Подбор обоев под пропорцию — по основному монитору на момент применения.

## 9. Откат

Подчиняется [REVERT](REVERT.md) и [EXECUTION-CONTRACT](EXECUTION-CONTRACT.md) без исключений:

1. Перед применением движок снимает исходные значения всех затронутых ключей, путь текущих обоев и текущей темы.
2. Откат возвращает значение, **только если текущее равно нашему**. Если пользователь после установки сам сменил обои или акцент, откат их не трогает и пишет «изменено пользователем, оставлено».
3. Файлы из `brand.assets.files` удаляются последними, после того как ни одна настройка на них не ссылается.
4. Toolbox: «Откат и отчёты → Оформление → Вернуть оформление Windows» — один прогон `revert` по всем `brand.*`.
5. Верификатор проверяет и применение, и откат: значения реестра, наличие файлов, путь текущих обоев.

## 10. Toolbox

Основа — стандартный Fluent / WinUI 3. Бренд выражается токенами, а не нестандартными контролами: так приложение выглядит «родным» и не ломается при обновлениях WinUI.

| Элемент | Решение |
|---|---|
| Фон окна | Mica (Mica Alt для области вкладок); при отключённой прозрачности — `Ink` / `Parchment` |
| Навигация | `NavigationView` слева, вкладки из [TOOLBOX](TOOLBOX.md) §2 |
| Акцент | собственные `AccentFillColor*` поверх системных ресурсов: Toolbox фиолетовый, даже если в Windows другой акцент |
| Тема | следует системной; переключатель в настройках Toolbox |
| Иконки | Segoe Fluent Icons (системные) + собственные глифы для понятий проекта: печать, руна, откат |
| Карточка твика | заголовок, риск (T1–T3 чипом), класс устойчивости, статус, «что ломает» раскрывается, кнопки «Применить» / «Вернуть» |
| Статусы | «Проверено» — `Proof` + печать; «Дрейф» — `Ember`; «Ошибка» — `Hex`; «Не применено» — нейтральный |
| Обзор | крупная печать системы: сколько карточек применено, сколько проверено, есть ли дрейф |
| Движение | стандартные переходы WinUI; одна фирменная анимация — «печать ставится» при успешной проверке, до 300 мс, отключается вместе с системными анимациями |
| Пустые состояния | иллюстрации в стиле обоев: линии, созвездия, руны |
| Доступность | контраст по §4, клавиатура везде, экранный диктор читает статусы словами, режим высокой контрастности — системные цвета без бренда |

## 11. Голос и тексты

Точно, коротко, на «вы» в интерфейсе. Говорим, что меняется и что ломается; не обещаем скорость без замера (D-014).

| Так | Не так |
|---|---|
| «Отключено 14 задач телеметрии. Проверено: 14 из 14» | «Система ускорена!» |
| «Вернуть как было» | «Отменить магию» |
| «Ломает: поиск в интернете из меню Пуск» | «Может повлиять на некоторые функции» |

Языки — русский, украинский, английский ([TOOLBOX](TOOLBOX.md) §5). Название не переводится: WizardOS.

## 12. Ассеты и структура

```
branding/
  src/            исходники: mark.svg, wordmark.svg, palette.json, параметры обоев
  out/            результат рендера (в git не хранится, собирается)
  LICENSE         CC BY 4.0 для изображений; код рендера — под лицензией репозитория
tools/branding/   скрипт рендера: знак во все размеры, обои, playbook.png, .ico, .bmp для OEM
Playbook/Images/  копии готовых файлов для .apbx (кладёт сборка)
```

`palette.json` — единственный источник цветов: из него строятся `.theme`, ресурсы WinUI и обои. Размеры знака: 16, 20, 24, 32, 48, 64, 256 px (`.ico`), 256 px (`playbook.png`), 120×120 BMP (OEM), 44/150/310 px для плиток и пакета MSIX.

| Этап | Когда | Результат |
