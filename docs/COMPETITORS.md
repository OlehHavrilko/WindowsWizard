Назначение документа — обосновать позиционирование ([DECISIONS](DECISIONS.md) D-014) и список отличий ([DIFFERENTIATORS](DIFFERENTIATORS.md)).

## 3. Что у них сильнее

Честный учёт — чтобы не строить отличия там, где мы заведомо слабее.

| Сильная сторона | Следствие для нас |
|---|---|
| Сообщество, узнаваемость, статус verified | не конкурируем охватом; публикация — после полной матрицы ([DECISIONS](DECISIONS.md) D-012) |
| Готовые GUI для настроек после установки (Toolbox, Revision Tool) | делаем свой Toolbox ([DECISIONS](DECISIONS.md) D-016); отличие — драйверы без браузера, отчёты, откат каждого твика |
| Глубина урезания | сознательно не соревнуемся ([DECISIONS](DECISIONS.md) D-008, D-014) |
| Годы накопленных исправлений под разные сборки | у нас одна целевая сборка и узкий набор — меньше поверхность |

## 4. Вывод

Поле «самая урезанная и быстрая Windows» занято, а его главное обещание не доказано (W-05). Свободно другое: **доказуемость и обратимость** (W-01, W-02, W-03, W-07). Их отсутствие — причина, по которой конкуренты либо избегают смелых изменений, либо применяют их без возможности вернуть. Отдельная незанятая ниша — машина, где одновременно игры, разработка и локальный AI (W-08).
