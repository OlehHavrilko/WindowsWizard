# База твиков: что есть у других и что берём

Сверка 2026-11-11. Источники: `config/tweaks.json` Chris Titus WinUtil (прочитан целиком), страница возможностей ReviOS и документация AtlasOS (по поисковой выдаче, требует проверки по первичным файлам). Решение о составе — [DECISIONS](DECISIONS.md) D-022, D-024.

Вердикты: **ядро** — применяется при установке; **стандарт** — пресет Toolbox, включён; **опция** — переключатель, выключен; **Lab** — с предупреждением и тремя условиями; **нет** — не берём.

## 4. Память в простое

Наблюдение владельца: на свежей системе занято около 10 из 32 ГБ. Часть этого — кэш (standby), который Windows отдаёт по требованию и который не является проблемой. Цель твиков — не цифра «занято», а три измеримые величины: выделенная память (commit) в простое, число процессов и число служб после входа. Их и фиксирует Bench Harness (F-06) до и после.
