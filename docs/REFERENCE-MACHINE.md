# Эталонная машина

Конфигурация ПК владельца по отчёту HWiNFO от 2026-11-11. Серийные номера, имя компьютера и пользователя намеренно не приводятся: репозиторий публичный. Все замеры и первые прогоны относятся к этой конфигурации.

| Компонент | Значение |
|---|---|
| Плата | GIGABYTE B550M AORUS ELITE AX, BIOS F8d (08.2026), платформа AM4 |
| Процессор | AMD Ryzen 5 5600 (Vermeer), 6 ядер / 12 потоков, без гибридных ядер |
| Память | 32 ГБ DDR4-3600, два канала, профиль XMP |
| Видеокарта | ASUS DUAL Radeon RX 9060 XT 16G, AMD Software Adrenalin 26.20 |
| Накопители | NVMe Kingston NV3 500 ГБ; второй накопитель 1 ТБ |
| Сеть | Realtek RTL8168/8111 (Ethernet), Realtek RTL8852CE (Wi-Fi 6E + Bluetooth) |
| Звук | Realtek ALC1220 |
| Монитор | Samsung LS27FG53x, 27″ |
| ОС | Windows 11 Pro x64, сборка 26300.9818 (26H2) |
| Безопасность | UEFI, Secure Boot включён, TPM 2.0 (AMD fTPM), HVCI выключен, Hyper-V активен |

## Следствия

| Наблюдение | Что это значит для проекта |
|---|---|
| Сборка 26300.9818 уже установлена | открытый вопрос Q-01 закрыт: 26H2 = 26300 подтверждено на живой системе |
| HVCI выключен, Hyper-V активен | исходное состояние VBS фиксируется как есть; инвариант — «не изменилось», а не «включено» |
| Только AMD (CPU, GPU, чипсет) | первая реализация драйверов — AMD Adrenalin и чипсет B550; NVIDIA и Intel делаются без собственной проверки на железе |
| Realtek: сеть, Wi-Fi, Bluetooth, звук | драйверы этих устройств — из каталога Windows Update; версии производителя платы — ссылкой |
| Нет гибридных ядер, десктоп | профили ноутбука и P/E-ядер не проверяются на этой машине |
| Один физический ПК | проверка новых сборок — по желанию владельца, на ВМ Hyper-V этой же машины |
