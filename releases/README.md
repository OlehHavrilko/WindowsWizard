# `releases/`

Готовые артефакты. Сами архивы в git не попадают (см. `.gitignore`), здесь остаётся только описание версий.

Состав релиза ([BUILD](../docs/BUILD.md) §5):

| Файл | Назначение |
|---|---|
| `WindowsWizard-<версия>.apbx` | playbook для AME Wizard |
| `WindowsWizard-<версия>.apbx.sha256` | контрольная сумма |
| `REPORT-<версия>.html` | отчёт тестового прогона |
| `REVERT.md` | инструкция по откату — рядом с файлом, а не только в репозитории |

Правила:

1. Архив под одним номером версии не перезаписывается: дефектная версия отзывается, выпускается новая.
2. Каждый релиз сопровождается записью: сборка ОС, версия AME Wizard, хеш базового ISO.
3. Публикация — только после полной матрицы ([ROADMAP](../docs/ROADMAP.md) v1.0).
